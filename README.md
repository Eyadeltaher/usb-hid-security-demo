# USB HID Security Demo

A hardware-based cybersecurity project demonstrating USB HID keystroke injection, controlled payload delivery, behavioral attack detection, and real-time security monitoring.

The project explores how USB devices emulating keyboards can introduce security risks to connected systems, how payload delivery can be demonstrated in a controlled environment, and how suspicious input behavior can be detected and visualized on Linux.

## Project Overview

The project is divided into four phases, covering both the attack simulation and defensive monitoring.

### Phase 1 — USB HID Attack

Demonstrate USB HID keystroke injection using an **Arduino Pro Micro (ATmega32U4)**.

The microcontroller emulates a USB keyboard and sends predefined keystrokes to the connected Linux machine.

**Key Concepts:**
- USB Human Interface Device (HID) protocol.
- USB keyboard emulation.
- Automated keystroke injection.
- ATmega32U4 firmware development.

### Phase 2 — Payload Delivery

Demonstrate the payload delivery stage through a controlled remote hosting environment.

A demonstration payload is hosted on a remote server exposed through **ngrok**. The firmware initiates a predefined HID sequence, while the Linux-side lab component handles retrieval and controlled execution of the payload.

**Key Concepts:**
- Firmware-controlled HID sequences.
- Remote payload hosting using ngrok.
- Controlled payload execution.

### Phase 3 — HID Attack Detection

Develop a Python-based detection engine to identify suspicious keyboard activity on Linux.

An initial threshold of **60 words per minute (WPM)** is used as an experimental baseline, combined with additional behavioral indicators to reduce false positives.

**Key Concepts:**
- Linux input-event monitoring.
- Python and `evdev`.
- Keystroke frequency analysis.
- Behavioral anomaly detection.
- USB device identification.
- Suspicious activity classification.

### Phase 4 — Detection Dashboard

Develop a dashboard application to visualize and monitor detection results generated by the Python detection engine.

The dashboard provides a centralized interface for observing keyboard activity, tracking suspicious HID behavior, and reviewing security events in real time.

**Key Concepts:**
- Real-time security monitoring.
- Detection event visualization.
- Suspicious activity alerts.
- Keyboard activity statistics.
- Detection history and event timeline.

## Project Goals

- Understand USB HID-based attack techniques.
- Explore the security implications of trusted USB input devices.
- Demonstrate controlled payload delivery.
- Develop behavioral detection mechanisms for suspicious keyboard activity.
- Visualize security events through a real-time monitoring dashboard.
- Explore defensive approaches to USB HID threats.

## Scope and Safety

This project is intended for cybersecurity education, authorized penetration-testing demonstrations, and defensive security research in controlled lab environments.

Payload delivery uses harmless demonstration scripts. No real keystroke contents or sensitive user information are collected by the detection engine.

All testing is performed on systems owned by the project developers or explicitly authorized for testing.
